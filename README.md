# rodesk

Robot Desk - A lightweight frontend workspace for robot interaction.

## Development

Environment:

- Ubuntu 22.04+
- Node.js 22 LTS
- pnpm 10+

Frontend:

- Vue 3
- TypeScript
- Vite
- Pinia

## Structure

```
rodesk/
├── web/          # Vue frontend application
├── desktop/      # Tauri desktop wrapper
├── mock/         # Frontend development mock environment
├── docs/         # Architecture and design documents
└── docker/       # Development containers
```
