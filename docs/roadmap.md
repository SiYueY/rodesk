# rodesk 开发路线

## Phase 1: Architecture Foundation

目标：冻结项目基础设计。

内容：

- 前端工程初始化
- Domain Model
- Communication Layer
- UI 基础框架

## Phase 2: Robot Experience

目标：实现机器人可视化。

功能：

- Robot Status
- Camera View
- Sensor Overlay
- Robot Workspace

## Phase 3: Teleoperation

目标：实现移动端机器人控制体验。

功能：

- Full Screen Video
- Dual Virtual Joystick
- HUD
- Safety Layer

## Phase 4: Agent Experience

目标：接入 Robot Agent。

功能：

- Conversation
- Tool Call
- Task Timeline
- Agent State

## Phase 5: Multi Platform

目标：支持多端部署。

包括：

- Web Browser
- Tauri Desktop
- Future Mobile

## 开发原则

- Web First
- Lightweight
- Component Based
- Robot Backend Independent
